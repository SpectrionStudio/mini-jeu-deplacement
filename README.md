# mini-jeu-deplacement
Mini-jeu de déplacement (HTML / CSS / JavaScript)

Petit projet web réalisé au lycée, permettant de déplacer un personnage (représenté par un carré) dans une zone de jeu à l'aide des flèches directionnelles du clavier.

Projet ancien / d'apprentissage — réalisé pendant mes années lycée, à l'époque où je débutais en développement web. Le code est volontairement simple, il s'agissait d'un premier test de manipulation du DOM et des événements clavier en JavaScript.

  Fonctionnement
Une zone de jeu délimitée par un cadre
Un personnage (carré rouge) positionné au centre
Déplacement du personnage avec les flèches directionnelles (haut / bas / gauche / droite)
  Technologies utilisées
HTML : structure de la page et de la zone de jeu
CSS : mise en forme de la zone de jeu et du personnage, positionnement absolu et transitions
JavaScript : écoute des événements clavier (keydown) et mise à jour dynamique de la position du personnage
  Structure du projet
mini-jeu-deplacement/
├── index.html
├── css.css
└── JavaScript.js
  Comment lancer le projet
Cloner ou télécharger ce dépôt
Ouvrir le fichier index.html dans un navigateur
Utiliser les flèches du clavier pour déplacer le personnage
  Statut du projet

Projet simple réalisé dans un contexte scolaire (lycée), conservé ici comme trace de mes débuts en développement web. Il ne sera pas retravaillé mais illustre mes premières bases en HTML/CSS/JavaScript.
